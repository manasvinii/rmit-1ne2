RMIT 1NE2 is an AI-powered student platform designed to bring personalised academic information into one place.

The platform connects with RMIT Canvas endpoints to retrieve student-specific information such as courses, assessments, grades, and academic activity. This information is used to build a student knowledge graph, helping the system understand a student's academic progress and provide more contextual responses.

Key Features

AI-powered academic chatbot

Personalised student information using Canvas data

Course, assessment, grade, and timetable retrieval

Grade and academic progress insights

Student progress tracking through a knowledge graph

Context-aware responses using LLMs

Classmate discovery based on shared courses or schedules
